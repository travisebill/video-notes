Google Cloud Tech 推出 Model Context Protocol 系列教学影片， 这是 MCP 系列第二集也是完结篇， 介绍如何用 ADK 建自己的 MCP server。 影片用九分多钟说明建 MCP server 的核心元件， 以及三个实际使用案例。 第一部分介绍建 MCP server 的核心元件：MCP library 提供框架， list_tools 和 call_tool 两个 handler 负责工具发现与呼叫， 连线机制在本地开发用 stdio、 production 用 streamable HTTP， 全部都是 async I/O 设计； 你的 MCP server 本质上就是 ADK tools 的包装器和翻译器。 第二部分展示三个使用案例。 第一个是 API MCP server， 以 load_web_page 为例， 展示 list_tools 暴露工具、 call_tool 呼叫 ADK tool 的完整流程， 可以用 ADK web 测试； 第二个是 database MCP server， 直接用 Google 开源的 MCP Toolbox for Database， 部署成 service 后用 MCP toolset 连接， agent 就能安全查询和分析企业资料； 第三个是 custom MCP server， 处理非标准工具如 Imagen 图片生成、 Veo 影片生成、 内部 REST API、 自订逻辑如数学计算， 也可以用 FastMCP library 简化部署； 透过自建 MCP server 你的工具就能贡献给整个 MCP 生态系。 整支影片的核心讯息是：建 MCP server 跟连接 MCP server 是 ADK × MCP 两集系列的两面， 建好 server 不只强化自己的 ADK agent， 更让工具对整个 MCP 生态系可用， 这就是从单独 agent 走向真正互联 AI 生态系的关键一步。
