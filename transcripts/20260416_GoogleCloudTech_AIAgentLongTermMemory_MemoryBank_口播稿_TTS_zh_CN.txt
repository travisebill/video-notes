Google Cloud Tech 推出 Agent memory 系列教学影片， 这是系列第三集也是完结篇， 介绍怎么帮 AI agent 建 long-term memory。 影片用六分多钟说明记忆银行的概念与 session service 的差异， 以及 preload memory tool 怎么自动捞回相关事实， 首先厘清 session service 管 active chat 跟即时对话， memory service 管 long-term archive 像档案柜； ADK 提供两种 memory service 选项， 包括简单的 in-memory memory service（适合本机快速测试但不跨重启、 只用基本 keyword search）跟 production 等级的 Vertex AI memory bank service（存云端、 支援 semantic search、 例如搜寻 two-wheeled vehicle 能找到 bicycle 的笔记）。 实作上用 agent engine 设定 memory bank， 选两个 model 包括一个从对话跟媒体抽取事实、 一个把事实 embed 起来做语意搜寻， 还能定义 topics 组织储存内容（像 user preference、 travel experience）， Memory bank 支援两种存入方式包括 add session to memory（会话结束时 archive 整个对话包含 message、 agent reply、 image/video/audio reference 抽取关键事实）跟 preload from file（直接上传 image、 video、 audio 档加文字 context 就能生成并储存事实）。 Preload memory tool 在每个 turn 开始时自动跑， 读 user 新讯息、 语意搜寻 memory bank、 抓最相关事实注入 prompt， agent 不需要特殊逻辑就能自动 enriched context， Demo 展示 long-term multi-modal recall， session A 用户分享历史建筑照片、 海边影片、 城镇音档存到 memory bank 后模拟重启跟时间过去， session B 全新对话问文化旅游推荐， preload memory tool 自动捞回 likes historical architecture、 enjoys seaside、 visited a town 等事实， agent 推荐符合的历史建筑景点， 整支影片的核心讯息是， AI agent memory 分三层， session + state 做 working memory， persistent sessions + user profile 做重启后跟新对话的个人化， memory bank 做 long-term 多模态 archive 加语意搜寻， 组合起来就能建构跨天跨周一致且 context-aware 的个人化 agent。
