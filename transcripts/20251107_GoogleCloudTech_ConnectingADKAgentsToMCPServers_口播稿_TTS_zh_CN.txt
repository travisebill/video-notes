Google Cloud Tech 推出 Model Context Protocol 系列教学影片， 这是 MCP 系列第一集， 介绍 ADK agents 如何连接 MCP servers。 影片用七分多钟说明 MCP 是什么、 为什么要用 MCP、 以及如何实际连接。 第一部分介绍 MCP 是什么——Model Context Protocol 是一个开放标准， 定义大型语言模型和 AI agents 与外部世界沟通的方式， 用 USB-C 埠做比喻：MCP 是 AI 的万用接头， 不用为每个工具写客制化连接器。 MCP 架构有两个重要角色——MCP server 暴露工具连接到资料源、 API 或自订动作， MCP client 探索并使用这些工具， 在 ADK 场景中 agent 通常扮演 MCP client 角色连接多个 MCP servers 取得新能力。 第二部分说明为什么要用 MCP——MCP 让 agent 更强大、 更可靠、 更实用：MCP server 暴露工具让 agent 能存取大量外部能力包括读写本地或远端档案系统、 查询 BigQuery 或 MongoDB 等资料库、 连接 Google Maps 取得即时路线、 使用 Imagen 等生成式媒体工具， MCP 也提供模组化和可重用性——MCP server 可以是独立服务任何符合 MCP 规范的 client 都能接入不需要客制化黏合代码， 此外 MCP 还有安全性和控制可以定义明确边界， 最后是简化部署策略——远端 server 可以把工具从 agent 解耦在 Cloud Run 或 GKE 等环境更容易扩展。 第三部分展示如何实际连接——ADK 用 MCP toolset 作为桥梁， 连接流程是先建立与 MCP server 的连接（可以是本地 process 或远端 HTTP server）， 然后载入所有可用工具把 MCP tools 翻译成 ADK 相容版本， 当 agent 决定使用某个 MCP tool 时 MCP toolset 会转发请求到 MCP server 并把回应送回 agent， 影片用 file system MCP server 和 Google Map MCP server 两个范例示范。 整支影片核心讯息：MCP 是 AI agents 的万用接头， 透过 ADK MCP toolset 可以轻松连接让 agent 与真实世界互动， 成为真正有用的 agentic system。
