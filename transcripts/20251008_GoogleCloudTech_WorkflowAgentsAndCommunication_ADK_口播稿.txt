Google Cloud Tech 推出 Google Agent Development Kit 系列教學影片，這是第二集完結篇。影片用將近五分鐘介紹 ADK 兩大進階主題：workflow agents 控制 agent 執行順序，以及 communication mechanisms 讓 agent 之間傳遞資料。第一部分介紹三種 workflow agent：Sequential agent 像組裝線，每個 sub-agent 依固定順序執行、傳遞結果，適合有順序相依的任務；Parallel agent 像 manager 同時派工給三個員工，適合獨立任務例如多 API 並行呼叫；Loop agent 重複執行直到條件滿足或達到最大迭代次數，適合除錯與迭代改進。第二部分介紹三種 communication mechanism：Shared session state 像共享白板，一個 agent 寫結果、下一個 agent 讀取；LLM-driven delegation 由 coordinator agent 像 CEO 看完需求後決定派給哪個 sub-agent；Explicit invocation - agent as a tool 把另一個 agent 包成 function-style tool，由 parent agent 決定何時呼叫。影片最後對比 sub-agent 與 agent-as-tool 的差異，Sub-agent 是組織圖的一部分永遠被 parent agent 管理，Agent-as-tool 像外部顧問用才叫不在 core hierarchy。整支影片核心訊息：multi-agent 系統需要 hierarchy 結構、workflow agents、communication mechanisms 三大支柱，ADK 透過這三加三的框架讓開發者建構結構化又靈活的多 agent 協作系統。
