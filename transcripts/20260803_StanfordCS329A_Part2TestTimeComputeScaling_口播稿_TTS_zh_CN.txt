本场 Stanford CS329A「Self-Improving AI Agents」系列 Part 2，由课程团队主讲，聚焦「Test-Time Compute Scaling」这个新典范。讲者开场便揭示核心张力：LLM 开发分为预训练、微调、推论三阶段，其中推论阶段在历史上几乎不被赋予算力，而这正是本讲要改变的观念。

从「Large Language Monkeys」论文出发，讲者展示一个惊人的发现：把同一个问题反复丢给 Llama-3 8B 或 70B 等次旗舰模型一百次，再用 verifier 从中挑选正确答案，最终表现竟可超越 GPT-4o 的单次作答。视觉化曲线显示，DeepSeek V3 在一千个样本后，于 coding 任务上击败 Claude 3.5 与 o1 preview。

更具理论意义的是，这套抽样行为服从幂次定律——coverage 对样本数 K 的关系近似为 1 减 A 乘以 K 的负 B 次方。讲者特别强调，这个幂次行为的成立有一个充分必要条件：资料集中必须存在难题的长尾分布。换言之，没有 long tail of hard problems，就没有 inference scaling。

讲者接著探讨 verifier 机制，举出数学领域的 formal proofs、编码领域的 unit tests、以及 AI as a Compiler 等完美验证的范例。然而实验显示，多数决机制在样本数大于 50 后几乎停滞，这就是所谓的 Generation-Verification Gap——模型其实生成出许多正确答案，但 verifier 抓不到。

在方法论层次，讲者区分平行抽样与序列修正两条路线，并介绍 Outcome Reward Model 与 Process Reward Model 的差异。引用「Scaling LLM Test-Time Compute Optimally」论文，他指出对容易与中等难度的题目，test-time compute 比扩大模型更划算；但对极难题目，更大的预训练模型仍然胜出。

最后，讲者介绍 Archon 框架，把 inference-time scaling 重新定位为架构设计问题。透过 Bayesian optimizer 组合 generation、fusion、critic、ranker、unit-test generator 等 inference operations，纯开源模型平均在指令遵循、推理、数学、编码任务上超越 GPT-4o 与 Claude 3.5 Sonnet 达 14.1%。

本讲最深层的启示是：与其追求单一更大的模型，不如设计可组合、可验证、可优化的推论系统。Inference 已从单纯的问答动作，演变为新一代 AI 系统的核心设计空间。

值得特别留意的是 Archon 论文中的 fusion 操作：把 K 个候选回答同时交给 LLM，请它综合成一个新回答——实验显示这个方法竟比 oracle selection 更强。这个反直觉的发现揭示了 LLM 在整合多重证据上的隐藏能力。

讲者也在结尾抛出多个延伸研究方向：如何针对极难题目设计 verifier、多个弱监督 verifier 的 ensembling、self-study 与 chain-of-thought 的剪枝整合、不同难度下 sequential 与 parallel 的最佳配比。这些都是尚未收口的开放问题。

整场讲座贯穿一条清晰的轴线：过去十年业界聚焦于扩大预训练规模，而 test-time compute scaling 开启了第二条同样可预测、可工程化的扩展路径。两条路并非互斥，而是互补——容易题用 inference 算力换表现，最难题仍需更大模型打底。

从后端工程的视角，这场讲揭示一个关键转变：推论成本从可忽略的固定支出，变成每次查询都会累积的变动成本。产品定价、API 设计、错误处理流程，都必须把这个新现实纳入考量。
