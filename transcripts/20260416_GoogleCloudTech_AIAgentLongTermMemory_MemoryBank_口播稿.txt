Google Cloud Tech 推出 Agent memory 系列教學影片，這是系列第三集也是完結篇，介紹怎麼幫 AI agent 建 long-term memory。影片用六分多鐘說明記憶銀行的概念與 session service 的差異，以及 preload memory tool 怎麼自動撈回相關事實，首先釐清 session service 管 active chat 跟即時對話，memory service 管 long-term archive 像檔案櫃；ADK 提供兩種 memory service 選項，包括簡單的 in-memory memory service（適合本機快速測試但不跨重啟、只用基本 keyword search）跟 production 等級的 Vertex AI memory bank service（存雲端、支援 semantic search、例如搜尋 two-wheeled vehicle 能找到 bicycle 的筆記）。實作上用 agent engine 設定 memory bank，選兩個 model 包括一個從對話跟媒體抽取事實、一個把事實 embed 起來做語意搜尋，還能定義 topics 組織儲存內容（像 user preference、travel experience），Memory bank 支援兩種存入方式包括 add session to memory（會話結束時 archive 整個對話包含 message、agent reply、image/video/audio reference 抽取關鍵事實）跟 preload from file（直接上傳 image、video、audio 檔加文字 context 就能生成並儲存事實）。Preload memory tool 在每個 turn 開始時自動跑，讀 user 新訊息、語意搜尋 memory bank、抓最相關事實注入 prompt，agent 不需要特殊邏輯就能自動 enriched context，Demo 展示 long-term multi-modal recall，session A 用戶分享歷史建築照片、海邊影片、城鎮音檔存到 memory bank 後模擬重啟跟時間過去，session B 全新對話問文化旅遊推薦，preload memory tool 自動撈回 likes historical architecture、enjoys seaside、visited a town 等事實，agent 推薦符合的歷史建築景點，整支影片的核心訊息是，AI agent memory 分三層，session + state 做 working memory，persistent sessions + user profile 做重啟後跟新對話的個人化，memory bank 做 long-term 多模態 archive 加語意搜尋，組合起來就能建構跨天跨週一致且 context-aware 的個人化 agent。
