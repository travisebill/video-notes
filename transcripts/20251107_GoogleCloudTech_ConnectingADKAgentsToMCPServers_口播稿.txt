Google Cloud Tech 推出 Model Context Protocol 系列教學影片，這是 MCP 系列第一集，介紹 ADK agents 如何連接 MCP servers。影片用七分多鐘說明 MCP 是什麼、為什麼要用 MCP、以及如何實際連接。第一部分介紹 MCP 是什麼——Model Context Protocol 是一個開放標準，定義大型語言模型和 AI agents 與外部世界溝通的方式，用 USB-C 埠做比喻：MCP 是 AI 的萬用接頭，不用為每個工具寫客製化連接器。MCP 架構有兩個重要角色——MCP server 暴露工具連接到資料源、API 或自訂動作，MCP client 探索並使用這些工具，在 ADK 場景中 agent 通常扮演 MCP client 角色連接多個 MCP servers 取得新能力。第二部分說明為什麼要用 MCP——MCP 讓 agent 更強大、更可靠、更實用：MCP server 暴露工具讓 agent 能存取大量外部能力包括讀寫本地或遠端檔案系統、查詢 BigQuery 或 MongoDB 等資料庫、連接 Google Maps 取得即時路線、使用 Imagen 等生成式媒體工具，MCP 也提供模組化和可重用性——MCP server 可以是獨立服務任何符合 MCP 規範的 client 都能接入不需要客製化黏合代碼，此外 MCP 還有安全性和控制可以定義明確邊界，最後是簡化部署策略——遠端 server 可以把工具從 agent 解耦在 Cloud Run 或 GKE 等環境更容易擴展。第三部分展示如何實際連接——ADK 用 MCP toolset 作為橋樑，連接流程是先建立與 MCP server 的連接（可以是本地 process 或遠端 HTTP server），然後載入所有可用工具把 MCP tools 翻譯成 ADK 相容版本，當 agent 決定使用某個 MCP tool 時 MCP toolset 會轉發請求到 MCP server 並把回應送回 agent，影片用 file system MCP server 和 Google Map MCP server 兩個範例示範。整支影片核心訊息：MCP 是 AI agents 的萬用接頭，透過 ADK MCP toolset 可以輕鬆連接讓 agent 與真實世界互動，成為真正有用的 agentic system。
