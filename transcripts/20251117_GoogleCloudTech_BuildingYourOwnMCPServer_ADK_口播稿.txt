Google Cloud Tech 推出 Model Context Protocol 系列教學影片，這是 MCP 系列第二集也是完結篇，介紹如何用 ADK 建自己的 MCP server。影片用九分多鐘說明建 MCP server 的核心元件，以及三個實際使用案例。第一部分介紹建 MCP server 的核心元件：MCP library 提供框架，list_tools 和 call_tool 兩個 handler 負責工具發現與呼叫，連線機制在本地開發用 stdio、production 用 streamable HTTP，全部都是 async I/O 設計；你的 MCP server 本質上就是 ADK tools 的包裝器和翻譯器。第二部分展示三個使用案例。第一個是 API MCP server，以 load_web_page 為例，展示 list_tools 暴露工具、call_tool 呼叫 ADK tool 的完整流程，可以用 ADK web 測試；第二個是 database MCP server，直接用 Google 開源的 MCP Toolbox for Database，部署成 service 後用 MCP toolset 連接，agent 就能安全查詢和分析企業資料；第三個是 custom MCP server，處理非標準工具如 Imagen 圖片生成、Veo 影片生成、內部 REST API、自訂邏輯如數學計算，也可以用 FastMCP library 簡化部署；透過自建 MCP server 你的工具就能貢獻給整個 MCP 生態系。整支影片的核心訊息是：建 MCP server 跟連接 MCP server 是 ADK × MCP 兩集系列的兩面，建好 server 不只強化自己的 ADK agent，更讓工具對整個 MCP 生態系可用，這就是從單獨 agent 走向真正互聯 AI 生態系的關鍵一步。
