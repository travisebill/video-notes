## 主題與背景

本集直播回放為科技 KOL 朱學恆於 2026 年 9 月 18 日主持的《朱學恆的萬事通事務所》單元，主軸鎖定 Anthropic 在 9 月 10 日發布、長達 154 頁的《Threat Intelligence Report on Chinese Distillation Attacks》（中國蒸餾攻擊威脅情報報告）。報告點名阿里巴巴、月之暗面 Moonshot、DeepSeek、智譜、小米、商湯、MiniMax 七家中國 AI 實驗室，指控其以工業化規模對 Claude 模型執行「model distillation」（模型蒸餾），僅阿里巴巴在三個月內就被記錄到 1.51 億次 API 交換。更令外界關注的是「鯉貓換太子」機制：Kimi 與 DeepSeek 把自家用戶請求靜默轉發給 Claude，意外將解放軍成都監控畫面、公安身分證比對系統、俄羅斯國防部資料等敏感內容送入美國模型訓練語料庫。

朱學恆在本集以「中國 AI 是假的」這個台灣政治評論場域的常見提問為切入，逐層解析 Anthropic 報告所描繪的五層攻擊結構，並穿插國民黨科技立委赴美訪問、以及 Anthropic 與川普政府之間的訴訟戰，最終落回台灣讀者應有的政策自保建議。影片長度 2 小時，屬於即時新聞型 commentary 而非深度訪談。

## 關鍵概念定義

| 名詞 | 定義 |
|------|------|
| Model Distillation | 蒸餾。透過讓學生模型模仿教師模型的輸出 logits 或 API 回應，把大模型能力壓縮進小模型的技術。本次報告指中國實驗室以此機制複製 Claude 能力。 |
| API Token Relay | API 代轉。實驗室 A 把用戶請求靜默轉發給實驗室 B 的 API 取得高品質回應，再回傳給自家用戶，雙方皆不知情。 |
| Threat Intelligence Report | 威脅情報報告。AI 公司內部的紅隊 / security team 撰寫、用於揭露對手戰術、技術與程序（TTP）的公開文件。 |
| IOC（Indicator of Compromise） | 入侵指標。可用來偵測特定攻擊者活動的 fingerprint，本次報告附上「部分可認證」級別的 IOC 供第三方驗證。 |
| Classifier | 分類器。在威脅情報 pipeline 中，先對可疑對話標記再人工調查，可降低全人工審查成本。 |
| 鯉貓換太子 | 朱學恆用語。指用戶以為在使用本地模型 A，實際回應來自於 Claude，造成「真實請求來源不可見」的歸因困難。 |
| state actor vs non-state | 國家行為者 vs 非國家行為者。Anthropic 報告強調對手法定上屬「國家級實驗室」，但技術上分為中央與地方兩種層級。 |
| Anthropic×白宮訴訟 | 2026 年 9 月法院判決：聯邦機構因為一家 AI 公司的言論與倫理立場而停用其產品，違反憲法。Anthropic 贏得部分勝利。 |
| 用腳投票 | 開發者社群以實際停用 Anthropic API 行動表達立場的現象，報告中提到「3,000 美金免費額」已大量回流。 |
| 川普「像狗一樣開除」 | 2026 年 8-9 月川普公開指責 Anthropic「激進左派」、下令聯邦機構停用的修辭用語。 |

## 核心主旨總結

Anthropic 9 月 10 號發布的 154 頁威脅情報報告，並非單純的「中國 AI 是假的」之政治口水，而是一份具體描繪 model distillation 五層攻擊鏈、API Token Relay 鯉貓換太子機制、以及 Kimi/DeepSeek 與 Anthropic Claude 之間 IOC 等級可驗證技術細節的威脅情報。報告的核心訊息是：中國 AI 實驗室的蒸餾行為已達工業級規模，且部分屬於國家級行為者的國家情報行動；與此同時 Anthropic 自身也因為與白宮的訴訟成為政治標靶，並非單純的「美國霸權白手套」。對台灣而言，這份報告的實質意涵在於——我們的對話資料可能透過 API relay 進入外國模型，而我們必須以法規、技術與公民素養三層次回應，而非停留在口水戰層次。
